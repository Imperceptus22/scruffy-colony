Der Nutzer wählte C am16.10.2026; verbindliche Referenz: [entwurf-C.png](entwurf-C.png), Issue V-61/#92. Erstellung zuerst, große Biomvorschau, fünf Originalvorlagen, kompakte Einstellzeilen und eine getrennte Kartenauswahl mit größerem Fokusbild und bebilderter Liste. Karteninfo öffnet per Name; echte Laufzeit, Items und Fortschritt stehen nur bei einer laufenden Karte.

Die zusätzliche Rückkehraktion direkt unter den Kampfaktionen wurde nach separater Vorschau vom Nutzer bestätigt. Der Knopf fordert die tatsächliche Rückkehr zur Welt an; wiederholtes Tippen während des Wartens gibt keine Soldaten auf.
